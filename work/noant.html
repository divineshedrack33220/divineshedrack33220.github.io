CASE STUDY · PRIVATE PRODUCT

NOANT Enterprise

An autonomous & human-in-the-loop AI customer support platform. High-confidence questions answered by an LLM; everything else escalated to a human in real time — across WhatsApp, Telegram, Messenger and web widgets.

The problem

Support teams drown in repetitive questions while customers wait hours for answers that an AI could have handled. Pure chatbots fail the moment a question needs judgment — and handoffs lose context.

The approach

NOANT uses a hybrid automation model: an LLM answers high-confidence questions instantly, and anything below the confidence threshold is escalated to a human agent with the full conversation attached. Custom Go vector search does semantic QA-pair matching before the model is even called — cheaper, faster, and more predictable than raw LLM calls.

  • Multi-tenant messaging hub: WhatsApp, Telegram, Facebook Messenger, embedded web widgets
  • Confidence-based triage: AI answer, AI + suggest, or human escalation
  • Custom embeddings & semantic QA matching written in Go — no external vector DB
  • Redis-backed job queue for async delivery and AI history
  • Subscription billing and credit packs via Polar

Stack

Go 1.25 + Gin · React 18 + TypeScript + Vite · LLM (Llama 3.3 via Groq) · TiDB Cloud (MySQL-compatible) · Redis (Upstash) · Polar payments · Render + Docker.

Outcome

A multi-tenant platform where AI handles the volume and humans handle the edge cases — with context preserved across the handoff. The agent runs the same triage pattern used in production.
