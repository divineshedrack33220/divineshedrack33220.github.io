CASE STUDY · OPEN SOURCE CORE

Mailgeko

Self-hostable email marketing — audiences, campaigns, automation and analytics in one deployable unit. The whole platform ships as a single Docker image.

The problem

SaaS email tools lock your contact data, take a cut as you scale, and can't run on your own infrastructure. Self-hosted alternatives are usually abandoned projects with painful deploys.

The approach

Mailgeko is built boring and portable: standard SQL, Redis-backed queues, signed webhooks, one container. The Next.js web app, the Go API and the async worker run side by side in a single image — as easy on a laptop as on a production VPS.

  • Contacts with CSV import, tags, custom fields, dedupe; lists + dynamic segments
  • Reusable templates with per-recipient rendering
  • Campaign scheduling with open/click/unsubscribe tracking
  • Analytics dashboards: series, links, devices, countries, per-recipient trails
  • Optional AI studio for subject lines and copy
  • Stripe (or local gateway) billing and sending limits
  • Delivery events via signed webhooks (Resend)

Stack

Next.js 16 · Go 1.25 · MySQL/MariaDB · Redis · Postgres + pgvector · Resend · Stripe · Docker (one image).

Outcome

A complete Mailchimp-class marketing stack you own completely.
